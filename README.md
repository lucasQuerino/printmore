# PrintMore

Imprima dezenas de PDFs, documentos do Word, planilhas do Excel, imagens e arquivos ZIP de uma vez no Windows, na ordem
certa, sem abrir um por um.

## Baixar

**[Baixar o PrintMore para Windows](https://github.com/lucasQuerino/printmore/releases/latest/download/PrintMore-Setup.exe)** (cerca de 50 MB)

Funciona no Windows 10 e no Windows 11 (64 bits). Não precisa instalar mais nada.

## Como instalar

1. Abra o arquivo baixado, `PrintMore-Setup.exe`.
2. Se o navegador avisar que o arquivo "não é baixado com frequência", escolha **Manter**.
3. Se aparecer "O Windows protegeu o computador", clique em **Mais informações** e depois em **Executar assim mesmo**.
4. Siga o assistente. Não é preciso senha de administrador.

Depois de instalado, o PrintMore aparece no menu Iniciar. Para mandar arquivos direto do Explorador de Arquivos,
clique com o botão direito neles e use **Mostrar mais opções → Enviar para → PrintMore**.

Da versão 1.3.0 em diante, o PrintMore avisa quando sai uma versão nova: é só clicar em **Atualizar** no aviso.
